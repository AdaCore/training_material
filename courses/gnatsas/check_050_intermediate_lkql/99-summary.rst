-----------------
What We Covered
-----------------

* **Expressions**

  * Conditional expressions :lkql:`if` and :lkql:`match`
  * List building without a *for* loop

    * Called "List Comprehension"

* **Functions**

  * Boolean rules
  * Unit rules
  * Support functions

    * :lkql:`@memoized` to allow caching

* **Patterns**

  * :lkql:`select` expression to find certain node types

    * Selector predicate to refine the selection

  * Matching tuples, lists, and objects
  * Using bindings to give a name to a selection result

* **Unit Rules**

  * Rules that apply to units rather than tokens
  * Required when the rule requires context

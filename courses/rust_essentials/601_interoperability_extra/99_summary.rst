* **C++ Interoperability**

  - A C-compatible facade hides C++-specific interfaces and contains exceptions
  - C++ bridge tools require a supported type set and project qualification

* **Adoption and Migration Strategies**

  - Narrow boundaries support incremental adoption, comparison, and rollback
  - Excessive calls, data movement, and shared state can make a boundary costly
  - Review ABI, ownership, callback, failure, and integration contracts
